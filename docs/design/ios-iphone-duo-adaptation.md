# iPhone Duo 自适应

## 边界与依据

沿用 iOS 三 Tab、校园左栏及原有详情/编辑入口。覆盖内外屏、横竖屏、左右 Split View 和连续窗口变化，最低目标保持 iOS 17；不改学校请求、持久化格式、云同步或共享协议，不同步改造 Android。

依据 Apple 的 [Prepare your app](https://developer.apple.com/iphone-duo/prepare/) 和 [Raise the bar](https://developer.apple.com/videos/play/tech-talks/111462/)。iOS 27.1 SDK 启用完整屏幕及原生竖向栏；保留 TabView、NavigationStack 和原生弹层，由系统决定适合符号或文字的栏轴，不将所有文字按钮强制塞进竖栏。前景遵循每一边的安全区，背景可以延伸到安全区外。

## 实现规则

- 布局使用当前容器几何与 Size Class；不以 iPad/手机型号、方向或主屏尺寸决定布局，不为 Duo 建第二套根界面。根导航、校园已访问内容、网络模型与编辑草稿的身份不随窗口宽度变化。
- 主课表和共享课表的宽屏能力依据 regular 水平 Size Class，实际网格/列表选择仍由现有空间测量决定。主课表尺寸变化时结束旧显示链接，翻页保留最近可见页，缩放动画落实其目标；原手势余下的累计位移在结束前不再生效。UIKit 滚动容器按节次行距重定位纵向位置，再约束到新滚动范围。
- 社区复用原双列投影；每列不足 128pt（随显示密度放大）或系统辅助功能字号时显示原顺序单列，最多两列。切换只影响卡片呈现，Feed/分页/筛选模型仍由原父视图持有。
- 评分筛选栏在展开搜索且宽度不足时通过 AnyLayout 改为上下排列，保留同一 TextField 子树与绑定；横向筛选条拥有明确高度。
- 日迹输入区接收持续变化的容器宽高；紧凑输入无法容纳编辑器和三个按钮时采用上下控制布局，草稿仍由同一输入组件持有。全屏输入为外侧留白保留高度预算，图片预览在短窗口中缩小但不删除附件。
- 带目标尺寸的 UI 图片解码显式传入环境 displayScale；无 UI 环境的原图解码默认使用像素尺度 1。分享图保持原模板宽度、内容与版式，沿用项目其他分享图的固定 3x 输出，避免随内外屏切换改变导出像素尺寸，不读取主屏。
- 分享扩展的状态与完成按钮位于安全区内滚动容器；大字号或短窗口可以滚动到完成按钮，导入任务不随尺寸变化重新启动。

## 静态核查覆盖

| 范围 | 保留或修正的路径 |
|---|---|
| 根导航/校园 | 原生 TabView/NavigationStack；校园左栏纵向滚动，已访问内容继续保留 |
| 登录/我的 | 登录为容器内 ScrollView、360pt 最大宽度；我的使用原生 List，表单及 Sheet 保留系统安全区 |
| 学业/教学表格 | 复用 AcademicDetailScrollContainer 的 840pt 内容上限；培养表格已有局部横向滚动 |
| 社区/评分 | 修正窄列及搜索栏；父层原有内容宽度限制继续生效 |
| 日迹/资料/媒体 | 原有尺寸驱动顶部、可滚动正文、scaledToFit 预览和系统 Quick Look；修正输入区容器与图像尺度 |
| Widget/分享图 | 不改 Widget 固定系统布局与分享模板尺寸；仅构建验证受影响扩展 |
| Share Extension | 安全区内滚动及 44pt 完成按钮 |

静态核查不构成界面截图或运行验收证据。

## 验证与验收

本地仅运行任务范围 SwiftFormat、只读风格/diff/配置检查和 Xcode 27.1 编译；build-for-testing 只生成测试产物，不执行 XCTest，不操作 Simulator。任务使用独立 DerivedData、单构建任务和关闭索引存储。新增 DuoAdaptiveLayoutTests 覆盖窄列阈值、输入高度预算、节次位置重映射、翻周/缩放动画中断、旧手势隔离及闲置尺寸连续变化；本轮不执行这些用例。按所有者最新要求，本轮以本地构建通过收尾，不推送分支、不触发或等待远端 CI；真机视觉与折叠/分屏交互由所有者验收。

CI 使用 xcode-27 runner 并显式选择 Xcode 27.1，保留 iOS 17 最低目标、固定 SwiftFormat 和离线 XCTest。发布前确认 Archive 仍使用 iOS 27.1 或更新 SDK；本任务不生成 Archive、不调整版本、不提交商店。

最终普通 Simulator build 已成功（App、Widget、分享扩展，arm64/x86_64；Xcode/iOS SDK 27.1，最低目标 iOS 17）；Info.plist、任务范围 SwiftFormat 和 diff 检查通过。新增 8 个回归用例曾随测试目标编译通过，未执行测试；其后收尾代码以普通 App/扩展构建验证。代码仅保留本地任务分支，未推送、未合入 main、未触发远端 CI。构建服务中断/等待的尝试不作为成功证据，本轮编译结果在 CURRENT 中记录。以下人工验收全部待完成，Issue [#44](https://github.com/IsaacHuo/MyLeafy/issues/44) 保留待验收状态，不能按构建成功关闭：

- 课表普通显示、翻周途中、缩放途中改变尺寸：日期/周次合理连续，旧动画不回写，节次与课程命中区域一致，滚动不越界。
