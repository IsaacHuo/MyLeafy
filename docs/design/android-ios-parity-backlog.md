# Android → iOS 功能补齐清单

日期：2026-10-23。本文记录当前 iOS 已有、Android 尚未对齐的用户可见能力，按优先级排列。`state/` 描述已经落地的状态；这里描述剩余工作。

## 已完成（本轮）

- 根导航三 Tab：课表 / 校园 / 我的；社区与日迹移入校园「校园生活」。
- 社区 TLS 证书拦截的可操作提示与停止无效重连。
- 评论回复、评论点赞、输入防抖搜索、帖子深链分享。
- 社区卡片真实头像、置顶标识、相对日期；评论头像。
- 个人资料真实头像、昵称 8 / 简介 80 限制与计数。
- 「找到我」卡片（邮箱 / 小红书）与五个 MyLeafy 主题页。
- 权限管理实时状态；免登录退出文案；设置分组文案对齐。
- 课表可信空结果保留、步骤式同步、下拉刷新覆盖层、提醒后台排期、可取消教务请求。
- 24dp 卡片体系、主题渐变、课程色同族化、alpha/描边 token、暗色层级。
- 评论 cursor 分页、Feed 缓存、通知 work 顺序、日迹读取错误保留、正文标签、图片继续缩尺寸、日程提醒级联、R8/CI 调整。

## P0

1. **课表设置引擎**：用户可编辑学期标签、第一周周一、1–24 节作息。
   iOS：`TimetableSettingsView.swift`、`UserTimetableSettings.swift`。
   Android：`SemesterConfig.kt` 固定 2026-2027-1，`TimetablePeriodSchedule` 固定 13 节。
   影响课表、提醒、导出、Widget（Android 无 Widget）、课程详情日期。工作量 L。
2. **社区草稿箱与自动保存**：iOS 有本地草稿、退出存入草稿箱、续编/删除。
   Android：`ComposePostScreen` 只有未保存确认。工作量 M。
3. **社区评论/帖子内容类型**：投票、附件（PDF/Word/Excel/Markdown）、投票列表与发布。
   Android 目前只有文本与图片。工作量 L。
4. **缓存清理与账户操作**：清除教务缓存 / 清除本地数据；绑定邮箱、删除账户。
   Android 只有缓存计数和逐项同步。工作量 L。

## P1

5. **课程冲突合并布局**：iOS 共享阶梯轮廓、四项以上汇总；Android 等宽车道。
6. **课程卡内备注与长按**：iOS 卡片显示备注、长按阅读与上下文菜单。
7. **时间视图 / 选周 Sheet**：设置卡、学期与假期分组、月历、倒计时。
8. **推送与提醒自定义**：iOS 5 类推送、自定义来源与提前时间；Android 3 类固定。
9. **日迹媒体**：图片/相机/语音/附件、长图分享、搜索/筛选/排序/置顶。
10. **日程导出**：TXT / ICS 全部个人日程；Android 只有随记 TXT 和课表 ICS。
11. **社区通知设置与删除**：静音、单条删除、公告、发布任务详情。
12. **运营 Banner**：可关闭图片横幅、深链/https 跳转、大字号竖排。
13. **图片全屏预览与缩放**：帖子详情图片点击、翻页、双指缩放。
14. **主题色与显示密度**：5 套主题色 + 自定义色；4 档字号/控件缩放。
15. **应用内语言**：跟随系统/简体中文/English；当前全部中文硬编码。

## P2

16. **成绩图表交互与排名分析**：逐点/逐段数值、最佳名次与段位卡。
17. **校园热力图**：按日期/节次聚合楼宇占用；Android 只有空闲教室矩阵。
18. **帮助中心章节化**：8 章目录/详情，替代单页说明。
19. **应用内反馈表单**：类型、正文、联系方式、设备信息；替代 mailto。
20. **社区个人主页与头像/封面**：他人主页、统计、公开帖子、头像上传与裁剪。
21. **课表分享图**：今日/本周长图，含备注、日程与考试。
22. **课表 ICS 范围/备注/考试**：剩余学期/自定义周次、备注与考试事件。
23. **课表背景实时预览与照片配色**：设置预览卡、从照片提取课程色。
24. **重要日期 / 倒计时日程**：全天/无结束时间语义与年时间线。
25. **统计热力图下钻与指标切换**：点日期看当日随记、记录天数/条数切换。
26. **社区搜索页下拉刷新、自动续页、浮动新内容提示**。
27. **举报理由五选一**。
28. **日迹内联输入器与长文全屏编辑**。
29. **免登录/学校身份的账户区差异化文案**（部分已完成）。
30. **登录身份本科生/研究生分段**：需要先补齐研究生 RSA+AES 链路。

## 明确排除

- iCloud 同步、CloudKit 签名与 iCloud 设置。
- iOS Widget、Share Extension、External Import 扩展。
- iOS「分享安卓版」卡片（Android 本身就是 Android 版本）。
- App Store 评分/审核演示/更新查询等 iOS 商店流程。
- iOS 26 Liquid Glass、系统 EventKit 等平台专属实现；Android 用现有 Material/ICS 等价能力。
