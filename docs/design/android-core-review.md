# Android 核心体验与 iOS 对比

评审日期：2026-09-30。参照当前主线 iOS；Android 使用独立 `.next` 安装和 API 36 模拟器。本轮按用户要求暂不检查小米真机。

## 比较依据

Android 的交互检查与布局图片来自模拟器上的实际 Compose 组件，图片使用独立合成数据；窄屏/平板布局通过测试密度控制，不冒充多个实体设备。iOS 依据主线源代码、既有设计与文案，没有同期 iOS 运行录像和帧时测量，所以以下不对 FPS、两端速度或审美给出虚构数值。

| 维度 | 当前 iOS 参照 | Android 本轮实现 | 仍需打磨或验证 |
|---|---|---|---|
| 登录 | 入口、表单与身份恢复连贯 | 北林/免登录同页；先恢复再导航，错误与验证码状态分开；本地进入和返回链路通过 | 真实学校验证码、会话过期后的重新认证需账号验收 |
| 课表流畅度 | 背景与内容分层，交互时复用投影 | 单一固定背景；翻周复用 20 周预计算结果；Pager 统一选周，显式跳转执行后消费 | 已验证行为；Debug 模拟器不能代替两端真实帧时比较 |
| 课表可读性 | 节次/起止时间竖排，课程信息按空间分配 | 5/7 天、13 节单屏；窄时间轴、课名/教室优先，完整信息在详情 | 当前字体、照片对比度与 200% 字号仍需逐张审阅；无障碍服务实操需后续 |
| 刷新反馈 | 真正执行的步骤与结果弹窗 | 下拉刷新只触发一次；真实阶段、事务保存、失败保留数据；身份过期转重新认证 | 学校线上 form/WebView 响应和网络中断链路仍待端到端确认 |
| 成绩美观度 | 紧凑摘要、学期列表与更丰富的图表 | 2×2 摘要、学期折叠、独立分析页、数值配合图形；GPA 只用官方值 | 趋势与分布目前采用基础条形呈现，视觉细腻程度仍有提升空间 |
| 校园组织 | 稳定目录、各工具独立 | 分类顺序和宽屏侧栏保留，紧凑行，数据失败不挡其他入口 | 教学长表格、日期编辑和长内容应继续统一细节 |
| 页面一致性 | iOS 系统组件与既有设计语言 | Compose 主题、返回栏、错误、表单与危险操作统一；五个 Tab 保持可达 | 不以复制 iOS 玻璃效果为目标；图表、空态与次要说明仍可继续减轻 |
| Cloudflare | 主线已切换新版 API | Android 已移除旧 SDK/运行路径，接入认证、资料、社区、图片、通知、评价与共享 | 本地契约通过；staging 当前维护模式阻断写入验证，不计作上线验收通过 |

## 本轮验证

- 根导航 7 项通过：本地进入、五个根入口、二级返回、帮助/设置、翻周和切 Tab 后状态保留。
- 固定背景/翻周/一次下拉与 Room 作用域、重开、破坏性升级、失败回滚已在 API 36 模拟器通过。
- Cloudflare 本地契约 9 项通过。部署 staging `/health` 返回 `environment=staging`；写入尝试在认证阶段返回维护错误，未改动服务器模式或生产数据。
- 完整 JVM 检查共 136 项：129 项通过，7 项跳过（6 项真实学校探测、1 项显式开启的 staging 验收）。Debug 构建通过；lint 无错误，仍有 97 条 warning、3 条 hint，不宣称零警告。
- 10 张模拟器布局图片覆盖登录、成绩、分析和校园，包含 360/600/840dp、浅深色、100%/130%/200% 字号组合；这不是每个页面的完整排列组合。8 张变更相关自动化基线逐张审阅，不能据此宣称全部子页视觉验收完成。
- 固定背景翻周短录屏保存在最新批次目录；自动化断言检查背景数量、位置和翻周后的状态，尚未进行两端帧时测量。
- 模拟器完整一轮 27 项中 26 项通过；随记返回测试等待系统键盘收起后，所属 3 项编辑测试复跑全部通过。最后修改的布局测试另行通过，8 张已审阅基线的 `verifyRoborazziDebug` 通过。未将分批复跑表述为重新执行全部 27 项。
- 本次调试 APK 指向 staging，免登录可在模拟器使用；后台维护期间不能用于确认远程功能已经上线可用。学校真实闭环与 staging 写入尚未验收，改动保存在任务分支，暂不并入可发布主线。

## 下一步顺序

1. **学校真实闭环**：以真实账号验证登录→获取课表→刷新无变化→断网保留→过期认证→恢复刷新，同时核对学校实际 HTML/form 与目标学期。不把解析样本通过等同于学校当前页面可用。
2. **隔离后台恢复后验收**：运行显式开启的 `CloudflareStagingContractTest`，验证资料清空、媒体重试、通知已读、评价与共享撤销。只访问固定 staging，使用临时测试身份并删除，禁止改到生产重跑。
3. **视觉细化**：先处理本轮截图发现的问题；随后统一成绩趋势/分布图、培养方案长表格的表头、日期表单和空态。保留安卓原生操作，不新增业务范围。
4. **运行质量**：Release/profileable 构建上测量启动、连续反向翻周和长列表帧时；采用同样数据和操作与 iOS 对照。再以 TalkBack 完成焦点、标签、相邻课程命中与大字号核查。
5. **真机收尾**：用户愿意恢复真机验收时，再检查小米字体、键盘、系统栏和图片背景；不反复截取老版本画面。
