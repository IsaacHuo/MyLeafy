# Android UI 与使用体验深化

本轮以现有功能为边界，保留五个根 Tab。Android 只提供北京林业大学与免登录两个入口，不提供通用学校或 Demo；免登录使用本机数据。页面文案优先取自 iOS，只对 Android 交互及已实现能力作必要调整。

以 [Emil 的设计工程 skill](https://github.com/emilkowalski/skills/blob/main/skills/emil-design-eng/SKILL.md) 的即时反馈、克制动效和可中断交互为参考，不引入 Web 依赖。

## 当前实现

- 手机根导航改为轻透圆角表面，宽屏保留侧栏；主窗口、根壳和系统导航区域使用一致的主题背景。普通按钮有 120ms 轻按反馈，根 Tab 立即切换，二级进场约 240ms。
- 统一中性分组背景、白色内容表面、圆角输入框与 inset grouped 设置列表；设置图标底板 32dp，保留至少 48dp 触控。
- 首次启动先恢复本机身份，无身份显示「选择入口」。免登录选择持久化，重新启动不会自动恢复旧的北林账号；进入本地模式时关闭社区客户端及后台会话刷新。
- 课表移除常驻空内容提示，周次栏下直接显示日期和网格，把纵向空间留给课程。课表保留 5/7 天、13 节和横滑切周。左侧按最新要求竖排节次、开始时间、结束时间，最小宽度 32dp，按实际系统字体测量；节次 10sp、时间 8sp，课程字号独立。跨节课程为地点预留空间，照片背景下为时间轴增加浅底。
- 课表在短屏、大字号组合下优先保留节次及开始时间，完整起止时间保留在辅助功能语义和课程详情中，不通过无限缩字保持三行。极小课程块以可见区域作为点击边界，常规控件保留 48dp 触控目标。
- 校园入口复用 `LeafyFeatureCard`，以图标底板、主副文字和弱化箭头形成层次，不再重复分类大标题。成绩、考试及教学培养保留原有请求范围；免登录不显示教务查询与同步入口，北林专属指南按身份显示。
- 社区查询区分当前选择与已加载内容归属，同查询失败保留内容，切分类清除旧内容；取消与过期响应不会回填状态，未读刷新失败保留旧值并记录诊断。
- 社区搜索支持键盘提交；发布保留文字进度，匿名选项整行可点，图片删除操作有足够触控范围。
- 日迹随记与日程各保留一个带文字的新增 FAB。删除随记使用 iOS「移到回收站」文案，编辑返回提供继续编辑或放弃确认。
- 我的显示学校名称、脱敏学号、昵称首字和当前外观设置。共享课表复制邀请码有反馈，停止、撤销及离开需确认，列表不再以 UUID 片段作为主要名称。
- 编辑表单保持滚动和键盘避让。错误横幅保留到重试、成功或主动关闭，部分成功中的失败提示也不会自动消失。深色启动背景与系统栏随实际主题显示。

## 文案来源

- 登录入口：`leafy/Features/Auth/LoginView.swift`。
- 随记空态、回收站：`leafy/Features/Schedule/Presentation/ScheduleRootView.swift`。
- 放弃编辑：`leafy/Features/Schedule/Presentation/ScheduleMemoAdvancedEditorViews.swift`。
- 校园入口说明：`leafy/Features/Discover/Presentation/AcademicEntrySections.swift`。
- 退出登录：`leafy/Features/Profile/Presentation/ProfileView.swift`。
- 共享操作：`leafy/Features/Profile/Presentation/TimetableSharingView.swift`。

Android 不照搬尚未实现的图片随记、附件、导入等功能说明，也不把实现术语写入普通入口介绍。

- 随记、日程和发布在 ViewModel 层拦截重复提交；取消不展示业务错误。日迹分区滚动、编辑草稿通过 Compose 保存状态恢复。
