# Android 对齐方案与取舍

Android 使用 Kotlin、Compose、Room、WorkManager、OkHttp，保留五个根 Tab；当前实现和行为约束以 [ARCHITECTURE](../../state/ARCHITECTURE.md) 为准，验证状态见 [CURRENT](../../state/CURRENT.md)。

## 对齐基准

以主线 iOS 和 `backend/src` 的 Cloudflare `/v1` 契约为准，不复制旧 Supabase 客户端。旧版服务继续运行，新 Android 不配置旧后台，也不在失败时回退。iOS/Android 共享业务语义、DTO、学校 HTML fixtures 与分析规则，不共享客户端源码。

界面文案沿用 iOS，仅适配 Android 能力和原生交互。只保留北京林业大学本科登录与免登录本地入口，不新增通用学校、Demo、研究生登录或未实现功能的按钮。

## 数据归属

- 学校教务直连，课程、成绩与考试以学校为权威，设备 Room 是副本。
- 日迹、个人日程、体育医疗记录等本地功能不引入后台依赖。
- 社区、资料、通知/公告、评价、共享与媒体使用 Cloudflare。Keystore 会话按 origin 与身份隔离；免登录不创建后台会话与订阅。
- 新 Room schema v7 允许破坏性重建，不维护旧 migration。独立 `.next` 测试安装保留用户原安装数据。

## 核心实现选择

1. 登录入口选择与学校表单同页；身份恢复完成后才建导航。学校认证成功与后台可用性分离。
2. 课表背景归根页，周分页只持有前景。投影随课程数据变化计算，翻周不重算全部教学周。
3. 学校课表从真实表单、链接、iframe 中获取必要字段，验证学期与结构，完整成功后事务替换。失败不清缓存。
4. 刷新展示真实阶段与结果，不编造百分比；重新认证后恢复原课表刷新，不顺带同步其他业务。
5. 成绩分析是纯计算模型，页面不反复统计。官方 GPA 不估算；课程编号、重修、文字成绩、零学分按 iOS 规则处理。
6. 校园目录独立于数据加载。查询结果绑定条件；编辑失败保留内容，成功才关闭。
7. Cloudflare 媒体发布保留幂等请求身份和 payload，重试检查已挂载图片。资料清空显式发送 null，删除共享关系使用后台关系 ID。

## 验证与发布

JVM 契约测试使用 MockWebServer，无生产写入。模拟器检查导航、作用域、事务失败、固定背景手势、布局与可达性；截图仅保留最新评审批次。Robolectric 基线必须逐张审阅后更新，不把录图成功当视觉通过。

真实学校登录/课表、隔离后台图片发布与共享权限仍需要端到端验证，不能被 MockWebServer 或本地 UI fixture 取代。最终回归前不发布 release tag。用户本轮已指定模拟器优先，小米真机延后。
