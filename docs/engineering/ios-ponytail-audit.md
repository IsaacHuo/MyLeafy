# iOS Ponytail 规则对照与优化

核对日期：2026-10-23。范围是 iOS App、Widget、分享扩展及相关测试。保留现有功能、最终视觉、数据权威和发布渠道。

规则来源为 [Ponytail](https://github.com/DietrichGebert/ponytail/blob/main/skills/ponytail/SKILL.md)（读取时 blob `d64edd32265ba21cbf5270158f04e97d96925f27`）和 [Ponytail Audit](https://github.com/DietrichGebert/ponytail/blob/main/skills/ponytail-audit/SKILL.md)（blob `ff9a95480700600fe2664d2d0906a4d750b2da0b`）。只采用其规则，没有安装插件、生命周期 hook 或成本统计。

## 阅读范围与负载

这是单用户设备上的校园 App。实际压力来自本机长列表、多张随记图片、教务 HTML、后台上传和跨身份异步任务；不按服务端多租户吞吐量设计客户端。

下表每个模块都核对后文全部 P/A 规则。证据来自入口和高风险调用链的直接阅读，结合全仓调用、测试及配置检索；不是逐文件穷尽证明，也不表示所有功能已完成运行验收。

| 模块 | 已读链路与配置 | 规则核对结论与运行边界 |
| --- | --- | --- |
| 启动与身份 | `leafyApp` → `AppModelContainerFactory` / `AppLifecycleCoordinator` → `CampusOperationScope`；`SchoolNetworkManager`、两类 Keychain 凭据、Demo 入口及备份、组合根、Xcode 配置 | 保留持久库恢复、身份/门户/会话代次、单测空宿主。没有把安全日志或 Keychain 删掉。Demo 备份恢复和真实账号仍需运行验收。 |
| 本地保存与文件 | 随记新建/录音/备注/高级编辑 → `ScheduleMemoPersistence` → `LocalModelSave` / `LocalFileCleanup`；对照 `LearningMaterialBatchImport` | F01 修复失败时全局撤销和移除媒体直接清理。其他资料模块的业务与存储不重写。 |
| 教务读取 | `SchoolDataPrefetchCoordinator` / 主动同步 → `SchoolDataSyncService` → `SchoolNetworkManager` → `HTMLParser` → 持久化与通知、Widget | F04 复用已有后台课表解析入口。保留异常页面、学期来源、缓存与过期响应保护；其他解析器没有仅因同步方法而跨线程传递 SwiftData 模型。 |

## 具体修复

| 编号 | 原行为与触发场景 | 最小修复 | 验证证据 |
| --- | --- | --- | --- |
| F01 | 随记保存遇到磁盘满时对共享 context 全局 rollback，可能丢掉其他待保存编辑；高级编辑提交后直接删文件，删除失败缺少持久重试意图 | 新建/录音共用插入撤销；备注/高级编辑仅恢复正文、标题、标签、时间及本次资源。移除媒体在提交前入现有清理队列；提交后清理警告不诱发重复保存 | `ScheduleMemoPersistenceTests`：插入失败、字段/媒体恢复、无关编辑保留、清理失败后重试、损坏队列阻止修改；已有 `IOSReliabilityTests` 文件清理回归 |
| F02 | URLSession 每次字节进度回调都编码并原子重写整个发布队列，还可能接收旧身份或已停止任务的迟到进度 | 进度只更新内存并保持单调；身份不符、停止状态和无变化进度不更新。路径及状态转换仍立即持久化 | `CommunityPublishCheckpointTests`：200 次进度不写盘、重启保留真实检查点、上传/校验路径落盘、写盘错误不被进度清掉、迟到回调拒绝；已有发布队列故障测试 |
| F03 | 随记列表及 Markdown 资源计算同步读盘，视图更新重复读取 | 生命周期 `.task(id:)` 使用显式文件 URL、资源 ID 和修订值；脱离主执行器读取并准备显示，取消/身份变化/替代任务后不应用旧结果。结果仅由当前 View 持有，离开页面释放；加载期间不误报图片损坏，没有新增全局图片缓存 | `ScheduleMemoImageLoadingTests`：同请求复用、修订/目录失效、取消可重试、替代请求、跨身份旧结果、离开释放、缺失/损坏文件；`ImageRefactorTests` 对照方向与最终渲染 |
| F04 | 完整同步在 MainActor 同步解析课表，与主课表的后台入口重复；等待解析新增取消窗口 | 复用 `TimetableRefreshUseCase.parseRecords`，向解析任务转发取消并在返回后检查取消；完整同步随后重验 `CampusOperationScope` | `TimetableTableParserTests`：后台/原解析结果一致、可信空、异常页面、取消；已有身份/门户/会话与异常缓存回归 |

## Ponytail 核心规则逐条对照

状态说明：**符合**仅指本轮实现和已读链路；**待运行验证**不等于通过；**不适用**说明本任务没有触发对应选择。

| 编号 | 原文要求的含义 | 状态 | 代码证据、应用或限制 |
| --- | --- | --- | --- |
| P01 | 用最少必要代码完整解决问题 | 符合 | F01–F04；新增代码承担具体保存/加载职责，没有增加产品能力。 |
| P02 | 交付说明未检查项和风险 | 符合 | 本文验证边界与最终交付报告。 |

| P04 | 首先判断功能是否必要 | 符合 | 保留用户明确要求的功能与视觉；没有新增开关或监控面板。 |
| P05 | 优先复用项目已有实现及惯例 | 符合 | F01 的 `LocalModelSave`/`LocalFileCleanup`，F04 的解析入口。 |
| P06 | 再使用标准库或系统能力 | 符合 | F03 使用 SwiftUI task、Swift Concurrency、UIKit 显示准备。 |

| P08 | 清楚的一行能表达时才用一行 | 符合 | 调用处复用保存/解析函数；事务撤销和取消检查保持可读多行。 |
| P09 | 其余情况写最少可用实现 | 符合 | 两个窄职责类型；没有通用事务框架、调度器或图片服务层。 |
| P10 | 完成调用方、测试、样本影响面 | 符合 | 四种随记保存和三处存储图片展示全部接入；相应回归测试随代码提交。 |
| P11 | 不增加无需求的抽象、转换、配置和未来代码 | 符合 | 沿用 Feature 分层与平台图片类型，不批量迁移 ObservableObject，不合并安全边界不同的服务。 |
| P12 | 在影响面完整的前提下保持 diff 简单 | 符合 | 没有格式化全仓或拆分大 View；仅删除经引用确认无调用的同步图片读取入口。 |

| P18 | 有明确限制的临时捷径标注升级时机 | 不适用 | 没有引入故意待替换的实现；不使用 shortcut 注释替代修复。 |

| P20 | 不删防数据损失错误处理 | 符合 | F01 增强保存和清理恢复；持久库备份/恢复及队列不可读保护保留。 |
| P21 | 不削弱安全 | 符合 | 没有改凭据、校园作用域、权限、请求幂等或日志脱敏。 |
| P22 | 不削弱无障碍 | 符合 | 照片标签、控件、字号及隐藏内容可访问性逻辑不变；真实 VoiceOver 仍待设备验收。 |
| P23 | 不拿结构检查代替硬件校准 | 待运行验证 | 不宣称帧时、峰值内存、耗电或 CloudKit 实际改善。 |

| P25 | 级别按用户要求选择 | 符合 | full；没有采用 ultra 级别的产品删减。 |

## 验证与未检查项

- 本地差异/分层检查通过；Xcode 27.0 的 arm64 generic Simulator `build-for-testing` 成功，App 最低部署目标核验为 17.0。App、扩展及测试代码仅编译，没有启动本地 Simulator 或执行 XCTest。19 项新增回归已编译；未改动的 `ClassroomLookupServiceTests` 有 7 处多余 await 告警，本轮文件没有新增编译告警。
- 远程现有 CI 执行离线 XCTest；任务分支当前提交必须通过 `CI result` 才能快进合入。实际提交与运行链接由交付报告提供，不在本文复制 Git 历史。
- 真机视觉、VoiceOver、真实学校会话、CloudKit、Widget 跨进程投递、Share 宿主唤起、Release 帧时/内存/耗电未在本地验收。
- 没有测量随记导入压缩、非课表 HTML 解析和社区草稿读写的耗时；这些路径没有被本轮结果证明无性能问题。未重写 Demo 备份和各资料工具的内部持久化流程，也未做全仓故障穷举。
