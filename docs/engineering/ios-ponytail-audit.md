# iOS 全仓 Ponytail 审计与优化

核对日期：2026-10-23。本轮按用户确认的 **full 级别、全仓 iOS 范围**执行，覆盖 App 全部功能和基础设施、共享源、Widget、分享扩展、测试、本地化、资源、工程配置及有关 CI/脚本。保留现有功能、最终视觉、数据权威和发布渠道；Android、后端和网站实现不在修改范围内，相关契约只读对照。

规则来源为 [Ponytail](https://github.com/DietrichGebert/ponytail/blob/main/skills/ponytail/SKILL.md)（读取时 blob `d64edd32265ba21cbf5270158f04e97d96925f27`）和 [Ponytail Audit](https://github.com/DietrichGebert/ponytail/blob/main/skills/ponytail-audit/SKILL.md)（blob `ff9a95480700600fe2664d2d0906a4d750b2da0b`）。仅采用规则，没有安装插件、生命周期 hook 或成本统计。

MyLeafy 是单用户设备上的校园 App，连接学校教务与社区服务，保存个人课程、记录和资料，并提供 Widget 与分享扩展。本轮按个人数据、有界媒体及异步任务负载评估。审计原文允许大仓抽样、仅输出报告；用户的全文件阅读和实施修复要求优先，相关适配在规则表明确记录。
