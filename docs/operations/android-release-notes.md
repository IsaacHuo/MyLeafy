# MyLeafy Android 1.2.9

面向 Android 10 及以上设备。

- 加固北林（BJFU）教务登录：表单编码与浏览器提交一致，代理字符与特殊字符不再导致登录失败；登录密钥无效、或提交后无法确认会话时给出明确提示，不再把登录页误判为已登录。
- 后台课表提醒使用已保存的作息与开学日期：冷启动后的课前提醒和排期校准不再退回默认设置，避免提醒时间错误。
- 课表设置页只读到已保存设置后才进入编辑：再次打开不再显示默认值、误报未保存更改或覆盖原有配置。
- 平板双栏校园页的同步结果（成功、部分失败、失败）提示在校园生活、自习、体育等所有领域都可见。
- 本地长跑提醒保存失败时在对话框内显示原因，保存中禁用保存与取消，避免重复提交。
- 保留 1.2.8 的网络连接优化、课表设置、校园全量菜单、社区紧凑卡片和课程详情分层。
- 课表、成绩与随记继续保存在本机；不采集或上传 App 前台使用行为统计。

候选包需管理员下载验收并确认后才正式发布。
