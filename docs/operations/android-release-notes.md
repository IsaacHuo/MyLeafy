# MyLeafy Android 1.2.7

面向 Android 10 及以上设备。

- 新增「课表设置」：可调整学年、学期、第一周星期一，以及每天 1–24 节的开始/结束时间；固定 20 周，设置会同步影响课表周次、时间轴和课程详情。
- 手机校园页改为按领域分组的纵向全量工具列表，工具一次点击直达；平板保留侧栏布局。
- 社区卡片日期改为 `10/9` 形式，点赞与评论合并为同一行，卡片更紧凑。
- 课程详情按信息、备注、提醒重新分层，统一字号与按钮宽度。
- 个人页先显示本机身份，不再等待社区资料请求；社区继续支持评论回复、点赞、输入防抖搜索和帖子分享。
- 课表、成绩与随记继续保存在本机；不采集或上传 App 前台使用行为统计。

候选包需管理员下载验收并确认后才正式发布。
