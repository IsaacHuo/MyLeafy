# MyLeafy Android 1.2.3

面向 Android 10 及以上设备。

- 课表优先呈现课名与地点，跨节课程可显示更多文字，重叠课程保持独立可点；空白网格更轻。
- 周次入口更明确，大字号下日期可换行；当前时间与今天标记会随时间更新。
- 成绩趋势补齐坐标与数值，多分类图表可左右滑动；教学章节与场馆资料更易展开阅读。
- 综素和体测输入、日迹卡片、社区摘要及更新说明改善大字号下的排版，统一全端提示与文字层级。
- 课程备注保存、提醒配置保存及权限不足分别提示。

Cloudflare 与 GitHub Releases 提供同一份正式签名 APK。下载后按系统提示覆盖安装，无需先卸载。
