# MyLeafy Android 1.0.1

此版本修复 Android 1.0.0 真机登录与社区网络错误提示，面向 Android 10（API 29）及以上设备。

## 本次修复

- 学校登录失败后会保留学校返回的错误，不再被自动刷新验证码立即清空。
- 社区安全连接被当前网络拦截时，显示切换网络或检查代理/VPN 的操作提示，不再展示底层证书异常。
- 保持 TLS 主机名校验；不会通过信任错误证书来绕过校园网络拦截。

## 当前限制

- 北京林业大学本科教务课表页面若返回未识别结构，Android 会提示课表数据不可用并保留缓存；WebView/bootstrap 回退尚未接入。
- 部分校园 Wi-Fi 会对外部 HTTPS 连接返回校园域名证书；此时需切换网络，社区服务本身不受影响。
- 云端共享课表、系统日程通知、Widget、后台同步、社区图片/附件与投票不在此版本内，对应入口会明确标注尚未完成。
- 学校数据依赖教务系统可用性，校外网络可能需要学校认可的 VPN。

Release 同时附带 APK、SHA-256 校验文件和包含源码 commit 的构建信息。iOS 不包含在此 Android Release 中。
