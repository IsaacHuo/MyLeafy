# MyLeafy Android 1.2.0

面向 Android 10 及以上设备。

- 教务会话过期后，使用本机加密保存的凭据与验证码识别尝试恢复，并继续原查询。识别不可靠时保留账号、密码，转为人工验证码输入。
- “我的 → 检查更新”改用 MyLeafy 的 Cloudflare 版本与下载服务，支持后台下载、安装包校验和系统确认安装。
- 完善首次教务同步、固定课表背景与时间轴、课程备注和提醒、成绩分析及校园页面的返回状态。
- 免登录保留本机功能，并允许匿名检查应用更新。

Cloudflare 与 GitHub Releases 同步提供同一份正式签名 APK、SHA-256 校验文件和构建信息。覆盖安装无需卸载，仍请保留需要的本地数据。

验证码识别不会上传图片；可靠识别率取决于学校验证码。教务更新需要可访问学校系统的网络。
