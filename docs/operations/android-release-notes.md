# MyLeafy Android 1.0.0

这是 MyLeafy Android 的首个可安装版本，面向 Android 10（API 29）及以上设备。发布构建已在 Android 16 / API 36 模拟器完成自动化验收。

## 本次包含

- 课表：7 天 × 13 节周网格、跨节课程与冲突并排、周切换、课程详情和当前日期/时间提示。
- 日迹：随记与个人日程的新增、编辑和删除；个人日程与课表共用同一份本地数据。
- 导出：按 `Asia/Shanghai` 生成课程与个人日程 ICS，并通过 Android 系统分享面板发送。
- 社区：分类、近七日热门、搜索、通知与未读状态、收藏、评论、发布，以及本人内容删除、举报和屏蔽。
- 校园：成绩、GPA、排名、考试和空闲教室；缓存失败时保留最近一次成功数据，单项同步不会扩大请求范围。
- 我的：社区资料编辑、主题和文字大小、缓存与同步中心、权限/帮助/反馈/关于，以及清理会话但保留身份作用域本地数据的安全退出。
- 品牌：启动图标与 iOS 使用同一母版，支持 adaptive 和 Android 13+ monochrome 图标；主要页面使用 Material 3 圆角与紧凑顶部栏。

## 当前限制

- 北京林业大学本科教务课表页面若返回未识别结构，Android 会提示课表数据不可用并保留缓存；WebView/bootstrap 回退尚未接入。
- 云端共享课表、系统日程通知、Widget、后台同步、社区图片/附件与投票不在此版本内，对应入口会明确标注尚未完成。
- 学校数据依赖教务系统可用性，校外网络可能需要学校认可的 VPN。

Release 同时附带 APK、SHA-256 校验文件和包含源码 commit 的构建信息。iOS 不包含在此 Android Release 中。
