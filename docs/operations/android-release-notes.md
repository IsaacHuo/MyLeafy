# MyLeafy Android 1.2.2

面向 Android 10 及以上设备。

- 校园现有子页对照 iOS 补齐：毕业进度、教学计划、成绩图表与导出、访客成绩和考试录入导入、综素材料、荣誉附件、医疗政策与台账、长跑、体测及场馆资料。
- 空教室支持单节、连续节次和指定教室全天状态，并可收藏常用教室。
- 教师、课程和菜品评分补齐筛选、分页、评分分布与明确提交。
- 社区首页和搜索采用双列卡片；课程详情默认半屏，信息排列更紧凑，编辑备注时展开并避让键盘。

Cloudflare 与 GitHub Releases 提供同一份正式签名 APK。下载后按系统提示覆盖安装，无需先卸载。
